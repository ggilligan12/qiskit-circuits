## qiskit-circuits

Small collection of IBM Qiskit quantum circuits for basic arithmetic tasks

### venv

To interact, clone the repo and `cd` into it, then configure a virtual env like so:

```bash
python3.13 -m venv quc_venv
```
```bash
source quc_venv/bin/activate
```
```bash
pip install -r requirements.txt
```
```bash
jupyter notebook
```
